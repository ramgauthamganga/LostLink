# LostLink

LostLink is a web-based **Lost & Found management system** designed to help students report, search for, and recover lost items within a campus environment.

The project was developed as an MCA mini project with a focus on making the process of reporting and finding lost items simple and organized.

## Features

- User registration and login
- Report lost or found items
- Search and browse reported items
- View detailed information about an item
- Submit claims for found items
- Track personal reports
- Notifications for relevant updates
- User profile management
- Admin dashboard for managing users and reported items
- User banning and account management

## Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- PHP

**Database**
- MySQL

**Development Environment**
- XAMPP

## How It Works

Users can create an account and report an item by providing details such as its name, category, description, location, and other relevant information.

Other users can search through the reported items and view their details. If someone believes they have found or lost a particular item, they can submit a claim through the system.

Administrators can manage users and reported items through the admin dashboard.

## Getting Started

### Requirements

- XAMPP
- PHP
- MySQL
- A web browser

### Installation

1. Clone this repository into the `htdocs` folder of XAMPP.

2. Start **Apache** and **MySQL** from the XAMPP Control Panel.

3. Create a MySQL database for the project.

4. Import the project's database SQL file into MySQL.

5. Update the database connection settings in the project if required.

6. Open the project in your browser:

```text
http://localhost/LostLink/
```
